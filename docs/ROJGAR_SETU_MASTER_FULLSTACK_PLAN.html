01 Project Architecture & Core Engineering Pillars

Rojgar Setu is an end-to-end open platform uniting informal workforce discovery across two massive Indian sectors:

1. Commercial & MSME Sector
Contractors, builders, logistics centers, workshops & factories hiring electricians, plumbers, masons, commercial drivers, warehouse helpers, and carpenters. Focuses on shift wages, trade certifications, multi-vacancy fulfillment, and rapid deployment.
2. Household & Domestic Gigs
Individual families, residential societies & homeowners hiring maids (jhadu-pochha-bartan), cooks, gardeners (mali), babysitters, and urgent home maintenance. Focuses on trust, Aadhaar verification, micro-radii (500m - 3km), and zero agency brokerage fees.

02 Complete PostgreSQL Database Schema (Relational + PostGIS + JSONB)

The following DDL script establishes the entire PostgreSQL data layer with relational constraints, PostGIS spatial indexing, and JSONB document flexibility: 

-- =========================================================================
-- ROJGAR SETU: MASTER POSTGRESQL + POSTGIS DATABASE SCHEMA
-- =========================================================================

-- 1. Enable Spatial & Cryptographic Extensions
CREATE EXTENSION IF NOT EXISTS postgis;
CREATE EXTENSION IF NOT EXISTS "uuid-ossp";

-- 2. Enumerated Data Types
CREATE TYPE user_role AS ENUM ('worker', 'employer', 'admin');
CREATE TYPE employer_type AS ENUM ('individual_household', 'business_msme');
CREATE TYPE wage_basis AS ENUM ('daily', 'monthly', 'per_job', 'hourly');
CREATE TYPE application_status AS ENUM ('applied', 'shortlisted', 'hired', 'rejected');

-- 3. Users Table (Core Auth & Identity)
CREATE TABLE users (
    id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
    phone VARCHAR(15) UNIQUE NOT NULL,            -- 10-digit Indian Mobile
    name VARCHAR(120) NOT NULL,
    email VARCHAR(120) NULL,
    role user_role NOT NULL,
    employer_category employer_type NULL,         -- Set if role = 'employer'
    password_hash VARCHAR(255) NOT NULL,
    preferred_lang VARCHAR(5) DEFAULT 'hi',       -- 'hi' (Hindi) or 'en' (English)
    is_phone_verified BOOLEAN DEFAULT FALSE,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);
CREATE INDEX idx_users_phone ON users (phone);

-- 4. Worker Profiles Table (Karigar Unified Profile)
CREATE TABLE worker_profiles (
    id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
    user_id UUID UNIQUE NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    karigar_id VARCHAR(30) UNIQUE NOT NULL,       -- e.g. "RS-DEL-8821"
    primary_trade VARCHAR(80) NOT NULL,           -- "Electrician", "House Maid", "Gardener"
    
    -- JSONB column for polymorphic skill checklists:
    -- Maid: {"jhadu_pochha": true, "bartan": true, "dusting": true, "cooking": "veg_only"}
    -- Electrician: {"wiring": true, "3phase": true, "inverter": true, "has_tools": true}
    -- Gardener: {"lawn_mowing": true, "pruning": true, "pesticide": true}
    skills JSONB NOT NULL DEFAULT '{}'::jsonb,
    
    experience_years INT DEFAULT 1,
    wage_type wage_basis DEFAULT 'daily',
    expected_wage NUMERIC(10, 2) NOT NULL,
    is_available BOOLEAN DEFAULT TRUE,            -- Availability Toggle
    
    -- PostGIS Spherical Geography Point (WGS-84 SRID 4326)
    location GEOGRAPHY(Point, 4326) NOT NULL,
    city VARCHAR(80) NOT NULL,
    locality VARCHAR(120) NULL,                   -- Colony / Society / Village
    pincode VARCHAR(10) NULL,
    
    -- Verification Badges JSONB (DigiLocker, AI Quiz, Police Check)
    -- {"aadhaar_verified": true, "mcq_passed": true, "mcq_score": "3/3", "skill_badge": "Certified Pro"}
    verification_badges JSONB NOT NULL DEFAULT '{}'::jsonb,
    
    rating_avg NUMERIC(3, 2) DEFAULT 5.00,
    total_reviews INT DEFAULT 0,
    bio TEXT NULL,
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

-- CREATE GIST SPATIAL INDEX (Replaces MongoDB 2dsphere)
CREATE INDEX idx_worker_location_gist ON worker_profiles USING GIST (location);
CREATE INDEX idx_worker_skills_gin ON worker_profiles USING GIN (skills);
CREATE INDEX idx_worker_trade_available ON worker_profiles (primary_trade, is_available);

-- 5. Jobs Table (Supports Commercial Sites & Domestic Household Openings)
CREATE TABLE jobs (
    id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
    employer_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    title VARCHAR(200) NOT NULL,
    category VARCHAR(80) NOT NULL,
    
    -- Sub-services requested (JSONB array)
    -- Domestic Maid: ["Jhadu-Pochha", "Bartan", "Dusting"]
    -- Site Electrician: ["Panel Wiring", "Conduit Laying"]
    sub_services JSONB NOT NULL DEFAULT '[]'::jsonb,
    
    timing_type VARCHAR(50) DEFAULT 'full_day',  -- 'morning_shift', 'evening_shift', 'weekend_gig', 'full_day'
    preferred_timings VARCHAR(100) NULL,         -- "07:30 AM - 09:30 AM"
    
    vacancies INT DEFAULT 1,
    wage_offered NUMERIC(10, 2) NOT NULL,
    wage_period wage_basis DEFAULT 'daily',
    description TEXT NOT NULL,
    
    -- PostGIS Location Point
    location GEOGRAPHY(Point, 4326) NOT NULL,
    city VARCHAR(80) NOT NULL,
    locality VARCHAR(120) NULL,                   -- "Grand Omaxe, Sector 93B"
    pincode VARCHAR(10) NULL,
    
    status VARCHAR(20) DEFAULT 'active',          -- 'active', 'filled', 'closed'
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX idx_jobs_location_gist ON jobs USING GIST (location);
CREATE INDEX idx_jobs_category_status ON jobs (category, status);

-- 6. Applications Table (Hiring Pipeline)
CREATE TABLE applications (
    id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
    job_id UUID NOT NULL REFERENCES jobs(id) ON DELETE CASCADE,
    worker_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    fit_score NUMERIC(5, 2) DEFAULT 0.00,
    status application_status DEFAULT 'applied',
    notes TEXT NULL,
    applied_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
    CONSTRAINT unique_job_worker UNIQUE (job_id, worker_id)
);
CREATE INDEX idx_applications_job ON applications (job_id, status);

03 PostGIS Spatial Query Blueprints & Micro-Radius Matching

The platform implements dual-tier spatial search: Micro-Radius (500m to 3km) for domestic household workers (maids, cooks, gardeners who work within their residential neighborhood) and Macro-Radius (5km to 15km) for commercial trades (electricians, plumbers, commercial drivers).

1. Micro-Radius Domestic Search SQL (`ST_DWithin` with Inline Distance)

-- Homeowner in Noida (Lng: 77.3639, Lat: 28.6080) searching for Maids within 2 KM (2000 meters)
SELECT 
    wp.karigar_id,
    u.name AS worker_name,
    u.phone AS worker_phone,
    wp.primary_trade,
    wp.skills,
    wp.expected_wage,
    wp.wage_type,
    wp.verification_badges->>'aadhaar_verified' AS is_aadhaar_verified,
    ROUND(ST_Distance(wp.location, ST_MakePoint(77.3639, 28.6080)::geography)) AS distance_meters
FROM worker_profiles wp
JOIN users u ON wp.user_id = u.id
WHERE wp.is_available = TRUE
  AND wp.primary_trade = 'House Maid'
  AND ST_DWithin(wp.location, ST_MakePoint(77.3639, 28.6080)::geography, 2000)
ORDER BY distance_meters ASC;

2. Django GeoDjango Implementation (`core/spatial.py`)

from django.contrib.gis.geos import Point
from django.contrib.gis.measure import D
from django.contrib.gis.db.models.functions import Distance
from .models import WorkerProfile, Job

def get_hyperlocal_workers(lng: float, lat: float, trade: str, radius_km: float = 3.0):
    """Fetches available karigars sorted by true spherical distance using PostGIS GiST index."""
    user_location = Point(lng, lat, srid=4326)
    
    queryset = WorkerProfile.objects.filter(
        location__distance_lte=(user_location, D(km=radius_km)),
        is_available=True
    ).select_related('user')
    
    if trade and trade.lower() != 'all':
        queryset = queryset.filter(primary_trade__iexact=trade)
        
    return queryset.annotate(distance=Distance('location', user_location)).order_by('distance')

04 AI-Powered Role-Specific MCQ Screening Engine (Gemini Flash)

During registration, once a Karigar chooses their trade (Electrician, Plumber, Driver, Maid, Gardener), the system runs an automated screening quiz powered by **Gemini 1.5/2.0 Flash** via strict JSON schemas:

1. Dynamic Generation
Django passes selected trade & language to Gemini API. Returns 3 practical, scenario-based safety & troubleshooting questions in <1.0s.
2. Mobile MCQ UI
Clean, accessible single-tap radio buttons with audio prompt icons for low-literacy workers.
3. Automated Badge
Score ≥ 2/3 awards a "Skills Tested ★" badge, immediately boosting profile visibility in employer search results.

def generate_role_mcqs(trade: str, language: str = "hi"):
    """Generates 3 practical MCQs using Gemini Flash with strict JSON output and fallback resilience."""
    lang_name = "Hindi (हिंदी)" if language == "hi" else "English"
    prompt = f"""
    Generate 3 practical, on-site multiple choice questions to evaluate a blue-collar worker in India applying for: '{trade}'.
    Language: {lang_name}. Focus on safety, tool knowledge, and practical troubleshooting.
    STRICT JSON Output only:
    [
      {{"id": 1, "q": "Question", "options": ["A", "B", "C", "D"], "correct": 0, "exp": "Brief explanation"}}
    ]
    """
    try:
        model = genai.GenerativeModel(
            model_name="gemini-1.5-flash",
            generation_config={"response_mime_type": "application/json", "temperature": 0.3}
        )
        resp = model.generate_content(prompt)
        return json.loads(resp.text)
    except Exception as e:
        print(f"[AI Service Fallback]: {e}")
        return FALLBACK_QUESTIONS.get(trade, FALLBACK_QUESTIONS["Electrician"])

05 Trust, Safety & DigiLocker Verification Architecture

For domestic hiring (maids, cooks, gardeners entering private homes), trust is paramount. However, forcing DigiLocker at initial sign-up causes a 70%+ drop-off. Rojgar Setu solves this via a Progressive Trust Funnel:

Tier Target Persona Verification Rail Friction & Speed Resulting Profile Badge
Level 1: Basic All Workers & Households Mobile Number + 4-digit SMS OTP 15 Seconds (Zero Friction) Phone Verified Account
Level 2: Skill Karigars / Trades 3 AI-generated MCQs (Gemini Flash) 45 Seconds "Skills Tested ★" Badge
Level 3: Trust Domestic Maids, Cooks, Drivers DigiLocker OAuth (Aadhaar / Driving License) or Parivahan DL lookup 2 Minutes (Optional) "Aadhaar Verified ✓" Green Tick Badge (3x higher hire rate)
Level 4: Entity Commercial MSME Contractors 15-Digit GSTIN or Udyam Registration Lookup Instant (Automated) "Verified Enterprise Employer" Badge
