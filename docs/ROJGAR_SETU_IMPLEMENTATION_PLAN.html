01 Executive Summary & JobsUPI Architectural Benchmark

Rojgar Setu is designed as a mission-critical digital bridge addressing India's fragmented informal, blue-collar, and grey-collar labor ecosystem. Millions of skilled tradespeople (electricians, carpenters, plumbers, delivery executives, drivers, masons, security personnel, technicians) struggle to discover regular local employment, while MSMEs, contractors, and household employers face high friction and middleman commissions.

The JobsUPI (https://www.jobsupi.com/) Architectural Philosophy:
Just as India's Unified Payments Interface (UPI) dismantled proprietary banking silos by creating an interoperable, zero-friction layer for instant fund transfers via mobile numbers, JobsUPI pioneered the concept of "Unified Employment Rails" for frontline workers. Rojgar Setu models its core pillars on JobsUPI:
  • Zero Middleman Brokerage: Direct connection via instant WhatsApp Click-to-Chat and Direct Mobile Dialing.
  • Hyperlocal Geo-Mapping: Automatic matching within a 2 km to 15 km perimeter using MongoDB 2dsphere index.
  • Voice & Multilingual Inclusivity: Intuitive bilingual (Hindi / English) interface tailored for low-literacy workers.
  • AI-Powered Fit Scoring: Algorithmic matching calculating skill overlap, distance friction, and wage expectations.

The database design leverages document-based modeling: embedding for composite sub-records (e.g. GeoJSON coordinates) and referencing for high-cardinality associations (e.g. applications linking workers to jobs).

04 Algorithmic Engine: JobsUPI-Inspired AI Fit Scorer

A core differentiator adapted from JobsUPI is the automated candidate-to-job matching calculation. When a worker searches for jobs or an employer reviews applicant pipelines, Rojgar Setu evaluates candidate compatibility through a deterministic weighted scoring function:

Total Fit Score (100%) = S_skill (45%) + P_geo (30%) + W_wage (15%) + E_exp (10%)
Factor Weight Formula / Heuristic Interpretation
Skill Overlap (S) 45% |Skills_worker ∩ Skills_job| / |Skills_job| Evaluates exact trade terminology and sub-competencies.
Proximity Score (P) 30% max(0, 1 - (Distance_km / Radius_max_km)) Calculates Haversine spherical distance via MongoDB GeoJSON.
Wage Alignment (W) 15% min(1.0, Wage_offered / Wage_expected) Guarantees worker expectation matches or exceeds employer budget.
Experience & Rating (E) 10% min(1.0, Exp_years / 5.0) * (Rating / 5.0) Rewards verified track records and client satisfaction.

05 Step-by-Step Implementation Roadmap

The following 6 implementation phases must be executed sequentially. Any developer or AI agent can follow these explicit milestones:

Phase 1: Environment Setup & MongoDB Atlas Connection Layer

  • Step 1.1: Initialize Django project directory structure: django-admin startproject rojgar_setu and app: python manage.py startapp core.
  • Step 1.2: Configure .env with variables: MONGO_URI, MONGO_DB_NAME, SECRET_KEY, DEBUG.
  • Step 1.3: Build core/db.py using PyMongo with automatic server-selection ping, connection caching, and graceful fallback to mongomock for offline environments.
  • Step 1.4: Register core in INSTALLED_APPS and establish the bilingual context processor in settings.TEMPLATES.

Phase 2: Authentication & Dual-Role Identity

  • Step 2.1: Create RegisterForm and LoginForm in core/forms.py with 10-digit Indian mobile number validation regex ^[6-9]\d{9}$.
  • Step 2.2: Implement register_view and login_view in core/views.py. Store user sessions inside request.session['rojgar_user'].
  • Step 2.3: On worker registration, automatically initialize a linked worker_profiles document with default coordinates and trade tags.

Phase 3: Hyperlocal Job & Worker Discovery Engine

  • Step 3.1: Build jobs_list_view supporting multi-parameter filtering: category, city, job_type, and keyword text search $regex.
  • Step 3.2: Integrate the MongoDB $near geospatial pipeline for radius queries based on client GPS coordinates.
  • Step 3.3: Render interactive Leaflet.js map with custom popups displaying job title, wage badge, category, and direct application links.

Phase 4: Hiring Pipeline & Direct WhatsApp/Telephony Integration

  • Step 4.1: Implement 1-click application submission in job_detail_view with duplicate application prevention via compound indexing.
  • Step 4.2: Build Employer Applicant Review Portal (job_applicants_view) displaying candidate fit scores and status toggles (Shortlist, Hire, Reject).
  • Step 4.3: Generate WhatsApp Web deep-links using format: https://wa.me/91[PHONE]?text=Hello... to enable instant hiring calls.

Phase 5: Analytics & Government Scheme Integration

  • Step 5.1: Build analytics_dashboard_view executing MongoDB Aggregation Pipelines:
    • $match active jobs → $group by category → compute average wage and vacancy counts.
    • Supply vs. demand matrix comparing registered karigars against open positions.
  • Step 5.2: Integrate resource links to National Career Service (14417 helpline), PMKVY, and PM Vishwakarma Yojana.

Phase 6: Testing, Seed Automation & Deployment

  • Step 6.1: Create Django management command core/management/commands/seed_data.py populating 10 vocational trades, 4 MSME employers, 5 verified karigars, and 5 active jobs across Delhi, Jaipur, Lucknow, and Bengaluru.
  • Step 6.2: Validate end-to-end responsiveness across mobile screen resolutions (360px to 1080px).
  • Step 6.3: Deploy database to MongoDB Atlas with IP Whitelist 0.0.0.0/0 and deploy application to Render, Railway, or AWS EC2.
